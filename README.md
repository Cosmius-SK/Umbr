# Project Umbr

Project Umbr is an evolving AI ecosystem. Its first AI entity is Embr, commonly called Em.

## Current focus

This repository is establishing Em's identity foundation and the project's architecture incrementally.

Em's confirmed identity and character decisions are documented in [Em Identity Core v0.1](docs/identity/Em-Identity-Core-v0.1.md).

The application, model integration, database, and deployment have not yet been implemented or configured.
